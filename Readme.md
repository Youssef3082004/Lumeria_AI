Welcome to the AI repository for Lumeria, the smart tourism application dedicated to enriching the exploration of Egypt. This repository houses the intelligence behind the app, focusing on personalizing tourist itineraries and understanding user feedback through advanced ML and NLP techniques.


## 📖 Project Overview

**Lumeria** is an interactive tourism Mobile application designed to help users discover Egypt’s most iconic landmarks, hidden gems, cultural stories, and traditional cuisines.
It combines **AI** and **AR** to offer a personalized and engaging travel experience for both tourists and locals.

## 🚀 Repo Overview

This repository is currently focused on developing two primary intelligent components:

### 1. Place Recommendation System
A personalized recommendation engine designed to suggest ancient sites, museums, diving spots, and other Egyptian landmarks to users based on their preferences and past ratings.

**Current Datasets:**
* `Places.csv`: Contains comprehensive metadata about various locations across Egypt, including coordinates, site types, historical eras, ticket prices, and key features.
* `Users.csv`: Contains the user interaction matrix, mapping specific users to the places they have visited along with their given ratings (1-5 scale).

### 2. NLP Sentiment Analysis
A Natural Language Processing model designed to analyze user comments and reviews left within the Lumeria application. This model classifies text as either **Positive** or **Negative**, allowing the platform to gauge user satisfaction, monitor the quality of experiences at different sites, and maintain a healthy community environment.
